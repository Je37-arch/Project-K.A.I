# Stage 0 inputs

## Required

- Analog Electronics course book, edition and relevant chapters, supplied privately.
- Actual syllabus and any educator-specific notation or assessment guidance.
- Baseline device: processor/chip, RAM, OS version and approximate free disk space.
- A bounded first unit selected after extraction inspection.

Do not include serial numbers, credentials, student names or textbook attachments in public issues.

## Optional

Five to ten real assignment, viva or concept questions. Check whether their text can be published before using public fixtures.

## Outputs

A source register with extraction quality, a unit coverage map, a baseline hardware description and development questions. Resource access for analysis and permission to redistribute a course pack are separate decisions. Record distribution rights before publishing student materials.

## Complete when

The first unit and its sources are identified, hardware is documented and Stage 1 can be run without guessing about inputs.
