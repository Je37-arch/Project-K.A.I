# Development roadmap

The project bible is authoritative for requirements and proposed acceptance thresholds. All implementation stages below are pending; no gate has passed.

| Stage | Deliverable | Exit evidence |
| --- | --- | --- |
| 0 Inputs | Book, syllabus, device inventory, bounded first unit | Source inspection and selected baseline device |
| 1 Feasibility | Extraction trial, two local configurations, retrieval-only baseline | Offline new answers; latency and memory report; documented limitations |
| 2 Core journey | One unit with modes, citations, follow-ups and abstention | Held-out quality evaluation before major simulator work |
| 3 Classroom | Roles, publishing, updates and query inbox | Isolation, version integrity and offline queue checks |
| 4 Analog Electronics | Diodes, supported clippers/clampers, transistor explorer | Reviewed reference fixtures and exact experiment context in chat |
| 5 Subject breadth | Radio Room, DLCD bench, Signal Guide | Each bounded demonstration works alone and through the guide |
| 6 Pilot | Educator onboarding and student trial | Core journeys completed; critical defects resolved |
| 7 Release 1.0 | Versioned application, model and course pack | Documented release checklist and owner sign-off |
